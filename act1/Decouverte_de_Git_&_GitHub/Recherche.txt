C'est quoi Git ?

   Git is a distributed version control system (VCS) used to track changes in files and manage different versions of a project. It helps developers work together, compare changes, create branches, and merge different versions of the code while reducing conflicts. Git also stores project history efficiently instead of creating a complete copy of the project for every version.

C'est quoi GitHub ?

   GitHub is an online platform that hosts Git repositories and allows developers to store, share, and collaborate on projects.

Quelle est la différence entre Git et GitHub ?	

   Git is the tool, while GitHub is an online platform that uses Git.
